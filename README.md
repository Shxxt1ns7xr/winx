# Winx Club: Fairies of Alfea (unofficial fan tribute)

Plain HTML + CSS + JavaScript with GSAP ScrollTrigger (included locally, no install needed).
Built from your own design: homepage, black-to-rainbow "Fairies of Alfea" transition, clickable fairies, a page per fairy
(Bloom, Stella, Musa, Tecna, Flora, Layla) with About Me and My Powers panels, a synthesized magic sound with mute, and legal pages.

## Run it in VS Code (Windows)
1. Unzip, then **File > Open Folder** and choose the `WinxClubFairies` folder.
2. Install the **Live Server** extension (you already use it on port 5500).
3. Right-click `index.html` and choose **Open with Live Server**. It opens at http://127.0.0.1:5500.
4. Click anywhere once so the browser allows sound, then scroll. The speaker icon (top left) mutes and unmutes.

## Edit your content
- `js/data.js`: Contact email, fairy text, colours and legal text.
- `css/style.css`: layout, fonts, sizes.
- `js/app.js`: all animations (hero glitch, gradient reveal, fairy scenes, panels).
- `js/sound.js`: the generated music (chords, notes, volume).
- `assets/`: your artwork, already cleaned: fairies have transparent backgrounds, and the logo and homepage collage have the black removed.
  To swap an image, replace the file with the same name (`assets/stand/bloom.webp` and so on).
